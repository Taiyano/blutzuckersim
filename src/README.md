# Source

<i>Last updated: 26/11/2026</i>

<h2>Click on the highlighted files to open the web source code viewer and editor.</h2>

This folder contains all the source code from this project. 

- <b><a href="https://taiyano.github.io/blutzuckersim/src/src-viewer/index.html">main.sb3</a></b>
This file contains all the code of the project ("sim.html")

- getDeviceCustomTurbowarpExtension.js
This file contains the custom turbowarp extension for getting the devices operating system to determine whether its a mobile device or not

- <b><a href="https://taiyano.github.io/blutzuckersim/src/src-viewer/launcher-src.html">launcher.sb3</a></b>
This file contains the launcher at "index.html"

- main-packager-settings.json
Packager configuration for main.sb3

- launcher-packager-settings.json
Packager configuration for launcher.sb3
